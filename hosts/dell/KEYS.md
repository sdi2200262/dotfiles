# Sway

```
Super+Enter              Open Herdr
Super+Shift+Enter        Open Ghostty
Super+W                  Open Firefox
Super+V                  Tile next window below
Super+F                  Float next window
Super+Shift+F            Toggle fullscreen
Super+Shift+Space        Float or tile focused window
Super+H/J/K/L            Focus left/down/up/right
Super+Shift+H/J/K/L      Move left/down/up/right
Super+left-drag          Move floating window
Super+right-drag         Resize floating window
Super+Shift+Minus        Park focused window
Super+Minus              Show or hide parked window
Super+Shift+Q            Close focused window
Super+1–4                Switch workspace
Super+Shift+1–4          Send window to workspace
Hold Super               Show bar
Super+/                  Open cheat sheet
Super+Escape             Lock
Super+Shift+R            Reload Sway
Super+Shift+E            Log out
Print                    Screenshot area
Brightness keys          Adjust brightness
Volume keys              Adjust volume
Mute key                 Toggle audio mute
Ctrl+Alt+F2              Rescue console
Ctrl+Alt+F1              Return to Sway
```
